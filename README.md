# Around The U.S.

## Descripción

Around The U.S. es una aplicación web interactiva desarrollada como parte del Sprint 6 del bootcamp de TripleTen. El proyecto permite al usuario editar la información de su perfil, crear nuevas tarjetas con imágenes, dar "Me gusta", eliminar tarjetas y visualizar las imágenes en un modal con un tamaño ampliado.

## Funcionalidades

- Editar la información del perfil.
- Agregar nuevas tarjetas mediante un formulario.
- Generar tarjetas dinámicamente utilizando un elemento `<template>`.
- Dar "Me gusta" a las tarjetas.
- Eliminar tarjetas del DOM.
- Abrir una imagen en un modal con su título.
- Cerrar los diferentes modales mediante sus botones de cierre.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Metodología BEM
- Manipulación del DOM
- Git
- GitHub
- GitHub Pages

# Around The U.S.

## Descripción

Around The U.S. es una página web interactiva desarrollada como parte del proyecto del Sprint 9.

El proyecto permite al usuario consultar y actualizar su información de perfil, cambiar su avatar, crear nuevas tarjetas con imágenes, dar y quitar "Me gusta", eliminar tarjetas y visualizar las imágenes en un modal con un tamaño ampliado.

En esta etapa del proyecto se integró una API para obtener y guardar la información del usuario y las tarjetas. También se continuó utilizando TypeScript y Programación Orientada a Objetos (POO), organizando la funcionalidad en diferentes clases y módulos.

## Funcionalidades

- Obtener la información del usuario desde una API.
- Obtener las tarjetas iniciales desde una API.
- Editar la información del perfil.
- Cambiar el avatar del perfil.
- Agregar nuevas tarjetas mediante un formulario.
- Generar tarjetas dinámicamente utilizando un elemento `<template>`.
- Dar y quitar "Me gusta" a las tarjetas.
- Eliminar tarjetas mediante un popup de confirmación.
- Abrir una imagen en un modal con su título.
- Cerrar los diferentes modales mediante sus botones de cierre.
- Cerrar los modales utilizando la tecla Escape.
- Validar los formularios antes de enviarlos.
- Mostrar el estado "Guardando..." mientras se procesan las solicitudes al servidor.
- Mantener los cambios realizados después de recargar la página.

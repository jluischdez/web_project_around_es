# Around The U.S.

## Descripción

Around The U.S. es una página web interactiva desarrollada como parte del proyecto final del Sprint 8.

El proyecto permite al usuario editar la información de su perfil, crear nuevas tarjetas con imágenes, dar "Me gusta", eliminar tarjetas y visualizar las imágenes en un modal con un tamaño ampliado.

En esta etapa del proyecto se realizó una refactorización utilizando TypeScript y Programación Orientada a Objetos (POO), organizando la funcionalidad en diferentes clases y módulos.

## Funcionalidades

- Editar la información del perfil.
- Agregar nuevas tarjetas mediante un formulario.
- Generar tarjetas dinámicamente utilizando un elemento `<template>`.
- Dar "Me gusta" a las tarjetas.
- Eliminar tarjetas del DOM.
- Abrir una imagen en un modal con su título.
- Cerrar los diferentes modales mediante sus botones de cierre.
- Cerrar los modales utilizando la tecla Escape.
- Validar los formularios antes de enviarlos.
